# 阳光3S遥感平台（测试版）

省 → 市 → 县 → 乡 → 村 五级下钻 + 真实卫星影像 + 遥感专题反演。

## 功能
- **全国遥感地图**：34 个省级行政区及九段线，五级逐级下钻
- **资质资格地图**：1422 条经营资质、271 条政策性农险资格上图
- **8 类遥感专题**：NDVI / 地上生物量 / 干旱指数 / 土壤墒情 / 有效积温 GDD /
  地表温度 LST / 洪涝淹没 / 冰雹大风
- **真实卫星底图**：Esri World Imagery（免 KEY 亚米级）
- **真实 Sentinel-2 反演**：NDVI / NDRE / NDWI / NDMI（免注册数据源）

## 快速开始
纯静态站点，无需构建。任选其一：
```bash
# 本地预览
python3 -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080/index.html
```

## 数据口径
- 行政边界：阿里云 DataV.GeoAtlas 公开边界服务
- 资质资格：专家包 08 库《阳光农险资质与政策性农险资格地区台账》，基准 2026-08-14，内部脱敏
- 影像底图：Esri World Imagery
